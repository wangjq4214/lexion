# 跨轮覆盖与遗忘曲线复习调度

**Spec ID:** 0002
**Status:** In Progress
**Date:** 2026-09-23

## Requirement

1. 每个单词本、收藏夹、错题本各自跨轮安排练习，使其中所有可练词最终都能被抽到，而非每轮独立随机造成长期遗漏；同一轮不重复，同轮数量仍遵循用户已选择的题数与集合实际大小。
2. 优先安排已经到期的复习词，但只要该来源还有未抽到的词，就为其保留每轮名额，避免持续有到期词时首次覆盖被饿死。
3. 依据遗忘曲线安排后续复习：初版按 `R(t) = exp(-t / S)` 预测保持率，按词及答题方向维护记忆稳定度 `S`；目标保持率初始为可调整的 90%，结果更新 `S` 与到期时间，而不是采用固定天数表。
4. 逐词考虑本题错误提交次数及提示级数：仅首次提交正确且未用提示是无辅助成功；提示、先错后对或跳过都促使更早复习；错误或提示次数越多，复习间隔越短。第三级提示按既有跳过语义处理，直接跳过不额外计错。
5. 同一英文—中文组合的中译英与英译中掌握状态分别维护；三个来源的覆盖独立，同一组合在不同来源的同一方向共用掌握状态，不同释义不合并。混合模式先确定方向再判断到期。保留现有三种练习模式和每轮统计，不将既有错题累计次数误当作本题提示次数或本次结果。

## Solution

按来源维护跨轮覆盖状态，并将“尚未抽到”与“已练且到期”作为不同候选集。每次开始或再练一轮时，从所选来源当前仍存在的词中，在请求数量内去重选择：已到期词优先；若尚有未抽到词，给首次覆盖留出非零名额，不能因连续到期而无限推迟；候选不足时仍可从其余可练词补足。选词和覆盖状态须跨重启持续有效；来源集合变更后以当前成员为候选，新增成员可首次覆盖。一次选中不等于掌握。

对相同英文—中文组合的每个答题方向维护一份跨来源共享的记忆稳定度 `S` 和复习时间；三个来源仍分别维护首次覆盖。初版用 `R(t) = exp(-t / S)` 预测距上次复习 `t` 后的保持率（`S > 0` 且时间单位一致），达到初始为 90% 且可调整的目标 `r` 时到期，即 `t_due = -S * ln(r)`。本题完成时，以本题提示级数、错误提交次数及是否跳过更新 `S` 并重新计算到期时间。无辅助成功延长后续间隔；困难反馈令下次更早到期，且更多提示/错误不能令下次比同条件下较少提示/错误更晚到期。后续成功可改善状态，历史累计错误不应永久锁死复习间隔。稳定度更新系数须经测试和使用反馈校准，不把模型预测值当成真实个体记忆概率。

选词身份必须既支持单词本范围内覆盖，也支持收藏和错题脱离原词本存活的配对身份；相同英文—中文组合跨来源共享方向性记忆状态，不同释义分开，单词本替换重建词条 ID 不能让收藏或错题练习失效。记录一次完整题目的结果，不以每次错误写入错题本的动作替代最终结果：错题本仍按每次错误提交累计其原有计数，包括同题反复错误；提示和跳过不能单独新增错题次数。刷新、异步写入或重练不应让一次题目完成被重复计入复习状态。混合模式在到期判断之前确定本题方向，所选题目的实际方向决定更新哪份掌握状态。

### Seams

| Seam | Connects | Expects | Provides |
| --- | --- | --- | --- |
| 练习请求 | `src/App.tsx` / `src/data/wordbooks.ts` ↔ Tauri wordbooks commands | 来源、当前单词本（如适用）、模式、所选题数 | 当前来源的不重复调度结果；空来源仍按现有提示处理 |
| 完成反馈 | 练习 reducer / App ↔ 复习持久层 | 本题配对、实际方向、错误提交次数、提示级数、正确或跳过、一次完成事件 | 持久的方向性稳定度和下一次到期时间；不影响既有本轮统计或错题累计语义 |
| 来源与状态 | SQLite 来源表 ↔ 复习调度 | 当前词本成员、独立保存的收藏/错题配对与其生命周期 | 各来源跨轮覆盖、每词方向性复习状态及到期查询 |

## End-to-End Tests

- **跨轮覆盖：** 给定一个词本或收藏/错题集合大于所选题数；连续开始多轮并完成，直到全部词首次出现；验证当前成员均至少出现一次、每轮无重复，即使有持续到期词也不会饿死未抽到词。
- **到期与未练冲突：** 同时存在到期词、未抽到词和未到期词；验证到期优先、仍为未练保留名额、题数不超过设置；未到期时仍能按现有入口主动开始练习。
- **遗忘与反馈：** 同条件下无辅助答对、提示后答对、一次及多次错误后答对、直接跳过、第三级提示跳过；验证到期先后与次数的单调关系，隔时到期并可再次选入；不依赖固定天数梯子。
- **分方向与跨来源：** 同一组合先在词本中译英练习，再在收藏夹同方向和错题本反方向练习；验证三个来源各自覆盖、同方向共享稳定度和到期时间、反方向独立，混合模式先确定实际方向再判断到期；不同中文释义不合并。
- **生命周期与恢复：** 收藏和错题跨原词本替换、重启后仍可调度；新增词进入首次覆盖，删除成员不再选出；一次完成不重复计算，错题每次错误提交继续独立累计。

## Decisions

- **每来源保证覆盖、同配对同方向跨来源共用记忆、混合模式先定方向、到期优先且预留未练容量：** 参见 [ADR 0004](../adr/0004-schedule-practice-with-coverage-and-due-review.md) 与 `.grimoire/CONTEXT.md`。
- **收藏/错题独立于源词本：** 沿用 [ADR 0002](../adr/0002-preserve-favorites-independent-of-wordbooks.md) 和 [ADR 0003](../adr/0003-preserve-mistake-records-independent-of-wordbooks.md)。
- **遗忘曲线而非固定间隔：** 依据用户确认的指数预测曲线、可调整的初始 90% 目标及 [ADR 0004](../adr/0004-schedule-practice-with-coverage-and-due-review.md)；更新系数需校准，不声称预测值等于实际个体记忆概率。

## Test Plan

- 以可控时钟与可控候选数据检验到期判定、跨轮覆盖终止性、提示/错误次数的单调性、再次成功后的恢复、空集和不足题数。
- 在 SQLite 测试重启、重导入、收藏移除/新增、错题累计、来源范围、同轮无重复和重复完成事件防护；在 App 测试模式/来源/题数、跳过、三级提示、同题多次错误与异步失败反馈。
- 用多轮桌面手动演练词本、收藏夹和错题本，并核查完成后的本轮统计没有改变。

## Out of Scope

- 将初始 90% 保持率或指数预测结果定义为不可调整的科学真值；其他曲线拟合方法不属于初版。
- 自动清空错题、自动取消收藏、修改现有提示与答题规则、改变错题计数语义。
