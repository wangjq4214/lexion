# 跨轮覆盖与遗忘曲线复习调度

**Spec ID:** 0002
**Status:** Implemented
**Date:** 2026-09-23

## Requirement

1. 每个单词本、收藏夹、错题本各自跨轮安排练习，使其中所有可练词最终都能完成练习，而非每轮独立随机造成长期遗漏；仅排进本轮（包括尚未展示的题目）不算完成覆盖，退出时未完成的题保留待练资格；同一轮不重复，同轮数量仍遵循用户已选择的题数与集合实际大小。
2. 同一来源下次开练时，上一轮未完成的词先占用名额，最多不超过本轮题数；剩余名额优先安排已到期复习词，并为尚未完成首次覆盖的词预留名额，避免持续有到期词时首次覆盖被饿死。
3. 依据遗忘曲线安排后续复习：初版按 `R(t) = exp(-t / S)` 预测保持率，按词及答题方向维护记忆稳定度 `S`；目标保持率初始为可调整的 90%，结果更新 `S` 与到期时间，而不是采用固定天数表。
4. 逐词考虑本题错误提交与提示级数：仅首次提交正确且未用提示是无辅助成功；提示、答错完成或跳过都促使更早复习；更多提示级数缩短复习间隔。答错提交即完成本题、最多计错一次；第三级提示按既有跳过语义处理，直接跳过不额外计错。
5. 同一英文—中文组合的中译英与英译中掌握状态分别维护；三个来源的覆盖独立，同一组合在不同来源的同一方向共用掌握状态，不同释义不合并。混合模式先确定方向再判断到期。保留现有三种练习模式和每轮统计，不将既有错题累计次数误当作本题提示次数或本次结果。

## Solution

按来源分别维护“已排进本轮但未完成”和“已完成覆盖”的跨轮状态；仅本题完成（含答错或跳过）时记录覆盖与本题复习结果。退出时未提交的当前题和本轮尚未展示的题均不得算作完成，也不得更新该题记忆；同来源下次开练时先从仍属于该来源的未完成词中选择，数量不足本轮容量时再沿用到期优先并给首次覆盖留出名额的规则。从所选来源当前仍存在的词中，在请求数量内去重选择；选词和待练/完成状态须跨重启持续有效；来源集合变更后以当前成员为候选，新增成员可首次覆盖。
同一来源的相同英文—释义组合只保留一条待练状态：若多个设备或轮次重复排入该词，以同步重放的确定顺序最后生效的排题身份取代旧身份；旧身份完成仍可更新本题记忆与覆盖，但不能清除新待练状态，新身份完成才清除该状态。旧版本排入却未提交的题目不追溯恢复，既有历史覆盖及记忆保留。

对相同英文—中文组合的每个答题方向维护一份跨来源共享的记忆稳定度 `S` 和复习时间；三个来源仍分别维护首次覆盖。初版用 `R(t) = exp(-t / S)` 预测距上次复习 `t` 后的保持率（`S > 0` 且时间单位一致），达到初始为 90% 且可调整的目标 `r` 时到期，即 `t_due = -S * ln(r)`。本题完成时，以本题提示级数、错误提交次数及是否跳过更新 `S` 并重新计算到期时间。无辅助成功延长后续间隔；困难反馈令下次更早到期，且更多提示/错误不能令下次比同条件下较少提示/错误更晚到期。后续成功可改善状态，历史累计错误不应永久锁死复习间隔。稳定度更新系数须经测试和使用反馈校准，不把模型预测值当成真实个体记忆概率。

选词身份必须既支持单词本范围内覆盖，也支持收藏和错题脱离原词本存活的配对身份；相同英文—中文组合跨来源共享方向性记忆状态，不同释义分开，单词本替换重建词条 ID 不能让收藏或错题练习失效。记录一次完整题目的结果，不以错题本写入动作代替最终复习反馈：答错完成时按现有规则累计一次错题次数；提示和跳过不能单独新增错题次数。刷新、异步写入或重练不应让一次题目完成被重复计入覆盖或复习状态。混合模式在到期判断之前确定本题方向，所选题目的实际方向决定更新哪份掌握状态。

## End-to-End Tests

- **跨轮完成覆盖：** 给定一个词本或收藏/错题集合大于所选题数；连续开练并完成多轮，直到全部词首次完成；验证当前成员均至少完成一次、每轮无重复，即使有持续到期词也不会饿死未完成首次覆盖的词。
- **未完成优先：** 一轮中查看当前题但不提交后退出（或在后续题提前退出，留下尚未展示的题）；下次选同一来源，即使还有到期词及新词，也先抽未完成的词。若未完成数量超过新题数，仅抽不超过题数的未完成词、同轮不重复；后续轮次仍可继续抽余下未完成词。
- **并行排题的待练身份：** 两设备从同一来源将同一词排入各自练习并同步；同步重放顺序最后生效的身份成为该词唯一待练身份，较旧身份的完成不能清除它，最新身份的完成可清除；两份完成反馈仍分别保持幂等。
- **完成与跨重启：** 同一轮答对、答错和跳过的题按原规则完成并记录覆盖及复习结果，未提交的题不记录完成/更新记忆；重启后选同一来源仍能重新安排未完成题。
- **到期与未练冲突：** 无上一轮未完成词时，同时存在到期词、未完成首次覆盖词和未到期词；验证到期优先、仍为首次覆盖留名额、题数不超过设置；未到期时仍能按现有入口主动开始练习。
- **遗忘与反馈：** 同条件下无辅助答对、提示后答对、答错完成、直接跳过、第三级提示跳过；验证到期先后与提示级数的关系，隔时到期并可再次选入；不依赖固定天数梯子。
- **分方向与跨来源：** 同一组合先在词本中译英练习，再在收藏夹同方向和错题本反方向练习；验证三个来源各自覆盖、同方向共享稳定度和到期时间、反方向独立，混合模式先确定实际方向再判断到期；不同中文释义不合并。
- **生命周期与恢复：** 收藏和错题跨原词本替换、重启后仍可调度；新增词进入首次覆盖，删除成员不再选出；一次完成不重复计算，错题每次错误提交继续独立累计。

## Decisions

- **排入与完成分离，未完成优先：** 来源覆盖只在题目完成时确认；同来源未完成题在下一轮先于到期与新词，占满前最多选到本轮上限；其余的每来源覆盖、同配对同方向跨来源共用记忆、混合模式先定方向、到期优先且预留首次覆盖容量沿用 [ADR 0011](../adr/0011-count-practice-coverage-on-completion.md)（承接 [ADR 0004](../adr/0004-schedule-practice-with-coverage-and-due-review.md)）与 `.grimoire/CONTEXT.md`。
- **收藏/错题独立于源词本：** 沿用 [ADR 0002](../adr/0002-preserve-favorites-independent-of-wordbooks.md) 和 [ADR 0003](../adr/0003-preserve-mistake-records-independent-of-wordbooks.md)。
- **遗忘曲线而非固定间隔：** 依据用户确认的指数预测曲线、可调整的初始 90% 目标及 [ADR 0004](../adr/0004-schedule-practice-with-coverage-and-due-review.md)；更新系数需校准，不声称预测值等于实际个体记忆概率。

## Test Plan

- 以可控时钟与可控候选数据检验：未完成优先于到期词、容量不足时剩余未完成词留待后轮、其余容量的到期与首次覆盖安排、到期判定、跨轮完成覆盖、提示/错误次数的单调性、再次成功后的恢复、空集和不足题数。
- 在 SQLite 测试排入与完成状态分离、退出/重启后重新抽未完成题、已完成题反馈幂等、来源成员变动、重导入、收藏移除/新增、错题累计、同轮无重复及重复完成事件防护；在 App 测试未提交退出、未展示题、答错后揭示答案再退出、跳过、模式/来源/题数、三级提示与异步失败反馈。
- 用多轮桌面手动演练词本、收藏夹和错题本，并核查完成后的本轮统计没有改变。

## Out of Scope

- 将初始 90% 保持率或指数预测结果定义为不可调整的科学真值；其他曲线拟合方法不属于初版。
- 自动清空错题、自动取消收藏、修改现有提示与答题规则、改变错题计数语义。
