# 单词考试

**Spec ID:** 0003  
**Status:** Implemented  
**Date:** 2026-09-24

## Requirement

1. 用户可以从指定单词本、错题本或收藏夹中选择一个考试数据来源，分别指定英译汉和汉译英的题数并开始考试。
2. 一场考试中的英文—中文词条不重复；两种题型的请求总数超过所选来源可用词条数时，应提示减少题数，而不是重复出题或悄悄缩减题数。
3. 用户写完答案后统一核对；核对前不逐题揭示正误。核对时展示各题正误，并按每题等分、空白算错、正确题数占总题数的百分比给出百分制分数。答案判定沿用现有练习规则：去除首尾空白后，汉译英忽略英语大小写，英译汉与存储的中文释义一致。
4. 考试中的每道错题（含最终核对时未作答的题）计入错题本一次；考试结果不改变练习的跨轮覆盖或复习进度。

## Solution

考试使用现有的三类持久化来源及所选单词本的词条，不把收藏或错题限制为必须有原单词本。按两种题型分别选定题数，从同一来源取得足量且互不重复的词条，确定每题方向；验证请求总数不超过来源可用量。考试作答状态与逐题提交、提示、跳过及复习调度的练习轮次分开，统一核对后展示每题答案和正误、正确数与百分制分数。使用现有答案匹配规则；错题按配对写入独立错题本并防止重复核对造成重复计数，不提交练习复习反馈。

### Seams

| Seam | Connects | Expects | Provides |
| --- | --- | --- | --- |
| 考试取题 | 考试界面 ↔ 单词本服务 / SQLite 来源 | 来源种类、指定词本、两方向题数；收藏与错题可脱离词本存在 | 足量、同场不重复的词条及题目方向；不足时明确反馈 |

## End-to-End Tests

- **双向混合考试：** 给定一个有足量词条的单词本，指定若干英译汉及汉译英题；开始后题数、方向分别符合设定，同场没有重复词条；作答过程中不显示正误，统一核对后显示各题正确答案、正误和正确数占总数的百分制分数。
- **不同来源：** 选收藏夹或错题本开始考试；即使没有任何单词本，只要所选集合有足量词条，仍可完成考试；选择具体单词本时仅从该词本取题。
- **题数边界：** 两种题型合计超过来源实际可用词条数或所选来源为空时，提示减少题数/选择有词条的来源，不静默截断、不重复出题；两方向均无题时不产生无意义的成绩。
- **答案与错题：** 英文大小写及首尾空白依现有规则判定；中文释义依现有规则判定；空白计错。核对后每道错题在错题本累计一次，重复查看结果不再增加；原单词本删除或替换后错题仍存在。
- **复习隔离：** 考试前后比较相同来源的练习覆盖和方向性复习状态，考试取题与核对均不改变它们。

## Decisions

- **错题记录与复习隔离：** 依照 [ADR 0006](../adr/0006-keep-exam-scoring-separate-from-practice-review.md)，考试错误（包括空白）进入错题本，考试本身不产生练习复习结果；重复查看不能重复计数。
- **来源生命周期：** 沿用 [ADR 0002](../adr/0002-preserve-favorites-independent-of-wordbooks.md) 和 [ADR 0003](../adr/0003-preserve-mistake-records-independent-of-wordbooks.md)，收藏与错题不依赖原词本持续存在。
- **题量和判定：** 沿用 [项目上下文](../CONTEXT.md) 中 exam-round 的不重复取题、数量不足、统一核对与百分制语义，以及 `src/domain/practice.ts` 的既有答案匹配行为；考试不使用 [ADR 0004](../adr/0004-schedule-practice-with-coverage-and-due-review.md) 所规定的练习调度来改变覆盖状态。

## Test Plan

- 在领域层验证两方向题数、不重复配对、评分及英中答案判定；在来源层验证词本/收藏/错题数量不足、独立生命周期与不修改复习调度。
- 在交互测试中验证核对前不泄露答案、统一展示结果、空白答卷、重复核对防重及错题写入失败后的安全重试。
- 桌面端分别演练三种来源，覆盖没有词本但有收藏或错题的情形。

## Out of Scope

- 考试结果参与练习复习调度、逐题即时判分、练习提示与跳过功能。
- 新增翻译同义词/语义模糊匹配规则；先沿用练习现有的精确答案判定。
