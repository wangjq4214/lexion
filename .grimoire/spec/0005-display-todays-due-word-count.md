# 展示今日待复习词数

**Spec ID:** 0005
**Status:** Implemented
**Date:** 2026-09-27

## Requirement

在首页展示所有单词本中今日需要复习的词数，在练习设置页展示当前选定单词本中今日需要复习的词数。两个数字均不纳入收藏夹或错题本。今日待复习指复习到期时间不晚于今天结束的词，包括逾期词；从未练习的词不计入。同一英文—中文组合在首页跨单词本只计一次；任一页面中即使两个答题方向都到期，该组合也只计一次。练习设置页的数字不随练习模式变化。

## Solution

复用现有持久化的逐组合、逐方向到期时间，以当前单词本成员限定候选范围，再按英文—中文组合去重。首页候选范围是全部单词本，练习设置页候选范围是选定单词本；只要任一方向有不晚于今天结束的到期记录，就计入该组合。没有复习到期记录的组合不计入，不将首次覆盖状态或选题名额误作待复习数量。展示计数不改变现有调度、练习模式或复习结果写入规则。

### Seams

| Seam | Connects | Expects | Provides |
| --- | --- | --- | --- |
| 待复习计数查询 | 首页与练习设置页 → `src/data/wordbooks.ts` / Tauri wordbooks commands | 全部单词本或选定单词本的查询范围、今日截止时间 | 按英文—中文组合去重的待复习词数 |
| 复习数据 | 计数查询 → SQLite 单词本成员及 `review_memory` | 当前词本成员、每个组合两个方向的到期时间 | 仅对有到期记录且在当前词本范围内的组合判定到期 |

## End-to-End Tests

- **首页汇总：** 两个单词本中有同一已到期组合，另有不同的已到期组合；打开首页，重复组合只计一次，显示两项的总数。
- **练习选择：** 切换选定单词本，练习设置页仅显示相应词本的到期词数；切换中译英、英译中、双向混合模式，数字保持相同。
- **今日边界：** 逾期和今天结束前到期的词被计入；尚未到期、尚无复习到期记录的词不计入；两方向都到期的同一组合只计一次。
- **来源隔离：** 只存在于收藏夹或错题本中的到期组合不进入上述两个数字。

## Decisions

- **按组合而非方向或词本出现次数计数：** 遵照 `.grimoire/CONTEXT.md` 的 `due-review-display-scope`；相同组合的复习时间按方向持久化且跨来源共享，参见 [ADR 0004](../adr/0004-schedule-practice-with-coverage-and-due-review.md)。
- **只计已形成复习到期记录的词：** 未练词属于现有调度的首次覆盖候选，但不属于此处的待复习数；沿用 [复习调度规范 0002](./0002-coverage-and-forgetting-curve-review-scheduling.md)。考试结果不更新练习复习状态，参见 [ADR 0006](../adr/0006-keep-exam-scoring-separate-from-practice-review.md)。

## Test Plan

- 使用可控时间及持久层数据验证逾期、当天截止、下一天、无到期记录、双向到期和跨词本重复组合。
- 在页面测试中验证首页汇总、切换词本与模式后的展示以及收藏夹/错题本不参与计数。

## Out of Scope

- 收藏夹、错题本各自的待复习数；更改选题优先级或首次覆盖规则；将考试结果计入练习复习进度。
