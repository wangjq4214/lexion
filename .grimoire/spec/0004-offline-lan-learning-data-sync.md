# 局域网离线学习数据同步

**Spec ID:** 0004
**Status:** In Progress
**Date:** 2026-09-26

## Requirement

1. 已配对的设备在同一局域网相遇时自动同步；每台设备离线期间仍可独立修改并使用本地学习数据，重连后自动合并，不依赖常在线主机。
2. 同步词书及其词条、收藏、错题记录与次数、复习覆盖与记忆进度，以及复习目标设置；当前选中的词书和未结束的练习轮次只保留在本机。同步不得改变已有收藏、错题及复习调度的业务语义。
3. 将各设备的变更按本机先后与跨设备因果顺序重放；无法比较先后的并发变更使用各设备一致的确定性顺序，后重放的修改或删除生效。不能依赖两台设备的系统时钟恰好一致来判定操作顺序；学习事件仍保留实际发生时间供复习间隔计算。重复交换、重连或中断不能重复计数或使设备结果分叉。
4. 使用 mDNS 自动发现局域网设备，用 Noise Protocol Framework 建立加密连接；首次连接手动核对界面展示的配对码，之后仅对已明确配对的设备自动连接和同步。A 配对 B、B 配对 C 不意味着 A 自动信任或同步 C。
5. 首次使用同步从各参与设备的全新学习数据开始；不要求合并功能发布前各设备独立积累的旧记录，也不自动删除现存数据。

## Solution

在 Tauri/Rust 持久化边界记录同步所需的学习变更，与本地 SQLite 写入共同提交；局域网通信交换彼此缺少的变更，按要求排序、去重和重放以更新本地数据，而不是复制另一台设备的 SQLite 文件或合并最终计数。为词书与词条提供跨设备稳定的操作目标；保留收藏/错题按英语规范化形式与中文释义识别配对、独立于源词书的既有生命周期。复习覆盖按来源独立、同一词义配对同方向的记忆状态跨来源共享；错题提交与练习完成结果分别作为可去重的学习事件，按原有规则计算累计次数和复习状态，考试错题仅影响错题记录，不改变复习进度。词书导入、替换和删除、词条删除、收藏变动、错题提交、练习调度与完成、复习目标修改都应经这一持久化边界处理，避免有本地写入绕过同步记录。

多设备重放保留每台设备自己的顺序与已知因果关系；并发操作使用稳定的一致规则排序，删除与修改同样适用后重放者生效。学习事件的发生时间独立于排序信息，复习计算在交换后仍能按相同输入得出一致结果；设备时钟不准时不能改变因果先后。网络中断后继续交换缺失变更，重复收到同一变更不应再次生效。连接前通过 mDNS 发现，首次配对双方核对与加密会话绑定的配对码；只保存经明确确认的设备信任关系，此后在 LAN 相遇时自动重连并同步，不向未直接配对的设备同步或透传来自未获授权第三方的数据。无法发现或连接时本地功能照常可用，等待下次相遇。

首发从用户自行清空旧数据后的新数据开始；实现不得执行自动清库或将旧库的汇总状态冒充可重放的历史事件。

### Seams

| Seam | Connects | Expects | Provides |
| --- | --- | --- | --- |
| 学习写入与变更记录 | `src-tauri/src/wordbooks/repository.rs`、`schedule.rs` ↔ SQLite | 已有词书、收藏、错题、复习和设置写入及其身份/发生时间 | 与本地业务结果一致的持久、可去重变更与可重放数据 |

| 设备互联 | Tauri 同步服务 ↔ 局域网对端 | mDNS 发现、Noise 安全连接、明确配对的设备身份和缺失变更 | 经授权的增量交换、断线续传与拒绝未配对设备 |

## End-to-End Tests

- **离线双向编辑：** 两台全新设备配对并断网后各自导入词书、增删收藏、完成练习；重返同一 LAN 后，两端得到相同的词书、收藏、错题计数、复习覆盖与记忆结果，当前词书选择及未完成练习仍各自独立。
- **重放与冲突：** 已同步同一词条后两端离线分别修改或删除；重连后按一致的因果/并发顺序生效，双方收敛；调乱设备时钟、重复交换及中途断线后重试不会令删除复活或重复计数。
- **学习语义：** 同一英语/中文配对在不同来源与答题方向练习，并在另一台设备提交错题及考试错题；重连后来源覆盖仍独立、同方向记忆共享、方向之间独立，考试错题不改变复习进度，一次提交只累计一次。
- **配对与信任：** mDNS 发现对端后首次展示并核对配对码；未确认或核对失败不能同步；已确认设备之后自动同步。A-B 与 B-C 分别配对时，A 不会因此直接或经 B 接收来自未配对 C 的数据。
- **不可用与首发：** 对端离线或 mDNS 不可用时可继续本地学习，恢复后同步；新数据从空库开始可用，功能不会自行删除设备上原有数据，也不会宣称旧汇总值已经被历史重放。

## Decisions

- 离线多主、全量学习数据范围、确定性顺序重放、设备本地 UI 状态和全新数据首发：依据 [ADR 0009](../adr/0009-support-offline-multi-device-lan-sync.md)。
- mDNS、Noise、首次配对码确认、重逢自动同步及禁止传递信任：依据 [ADR 0010](../adr/0010-discover-lan-peers-with-mdns-and-display-pairing-code.md)。
- 收藏与错题生命周期独立于词书；来源覆盖独立、记忆进度按词义配对及答题方向共享；考试结果不更新复习进度：依据 [ADR 0002](../adr/0002-preserve-favorites-independent-of-wordbooks.md)、[ADR 0003](../adr/0003-preserve-mistake-records-independent-of-wordbooks.md)、[ADR 0004](../adr/0004-schedule-practice-with-coverage-and-due-review.md) 和 [ADR 0006](../adr/0006-keep-exam-scoring-separate-from-practice-review.md)。

## Test Plan

- Rust/SQLite 集成测试覆盖写入与变更记录的原子性、重启后的设备身份与去重状态、两端及三端不同交换顺序、词书替换/删除、收藏独立性、错题去重、复习事件重算、断线重连和系统时钟偏差。
- 桌面手测覆盖首次发现与码核对、核对失败、重复连接、断网学习后自动合并、局域网发现不可用时的反馈以及多设备权限隔离。
- 以前后两端可见状态和既有练习/考试语义作为验收依据；不把仅传输成功视为数据同步成功。

## Out of Scope

- 首次配对时合并两个功能发布前已独立使用的旧数据库、重建不存在的旧操作历史，以及自动清理旧数据。
- 云端中继、跨公网同步、未配对设备之间的间接传播；mDNS 不可用时的手动地址发现属于后续另议。
- 将未结束的练习轮次或当前设备的选词状态作为跨设备实时会话迁移。
