# 自动交换与端到端同步

**Ticket ID:** T0005
**Source:** [Spec 0004](../../spec/0004-offline-lan-learning-data-sync.md) §Requirement 1–5；[ADR 0009](../../adr/0009-support-offline-multi-device-lan-sync.md)、[ADR 0012](../../adr/0012-relay-applied-operations-through-paired-devices.md)
**Status:** In Progress

## Goal

已明确配对的设备在 LAN 再次相遇时自动、安全地交换缺失学习变更，断线后恢复并更新可见数据；完成双设备与三设备端到端验收。

## Affected Surfaces

- **Rust/SQLite 操作日志与同步服务：** 基于 T0001 的持久原作者/序号/因果关系，向已配对对端按原始作者增量导出所有已生效操作（含第三方日志）、补缺/去重/重放，并经 T0004 的 Noise 会话安全交换和重连。
- **Tauri/前端：** `src-tauri/src/lib.rs`、`src/data/wordbooks.ts` 与同步界面的连接状态、同步结果/错误反馈及必要的数据刷新。
- **端到端验证：** 词书、收藏、错题、复习和设置跨两台/三台设备的离线合并，局域网不可用与重复接收。

## Approach

发现已配对对端后自动发起经身份校验的 Noise 连接，交换各原始作者的已应用进度，按作者及序号补齐双方缺少的所有已生效变更（包括对方转发的第三方操作），保留原作者、原操作身份和因果前置关系；接收方信任直接配对的发送方对第三方来源的声明，不要求第三方逐条签名。补齐缺失前置操作后，按 T0001 的一致顺序重放 T0002/T0003 的内容与学习事件，转发不得当作发送方新操作或重复计数。断线和重试不能造成漏项或重复计数；在完成持久化后刷新受影响的展示，不覆盖当前选中的词书或未结束的练习。对端离线、mDNS 不可用或配对失败时维持本地功能并向用户呈现状态。A-B 与 B-C 分别配对后，A 可以通过 B 接收 B 已生效的 C 操作，但 C 不能未经直接配对就连接 A。首发只验收新数据，不自动删除旧数据。

## Dependencies and Coordination

- **Blocked by:** T0001（持久身份/增量与幂等重放）；T0002（词书与收藏操作）；T0003（错题、复习和设置操作）；T0004（先有明确配对的安全连接）。这些都是本票完整端到端验收所必需。
- **Blocks:** 无。
- **Coordination risks:** 与 T0004 共享会话及配对界面，与 T0002/T0003 共享写入后的数据刷新契约；先核对接口，再接入自动交换，避免网络重试直接触发重复业务写入。

## Acceptance

- [ ] 两台全新设备首次核对配对码后分别离线产生词书、收藏、错题、复习和设置变更；再次在同一 LAN 相遇无需人工触发即自动交换，两端最终数据和已确定的业务语义一致。
- [ ] 网络中断、重启、重复连接及乱序抵达后继续交换缺失变更；无重复错题计数、复习完成或已删除词条复活，双方最终收敛。
- [ ] A-B、B-C 分别配对，C 产生 C1 并与 B 同步应用、随后离线；B 在看到 C1 后产生依赖 C1 的 B2。A 仅与 B 相遇即可按原始作者收到 C1 再应用 B2，保持 C1 的作者 C 与序号不变；其后 C 与 B 相遇，各端最终收敛，无重复计数。A-C 未配对时 C 仍不能直接连接 A；未确认/身份不符设备无法直接读写同步数据。
- [ ] A 从 B 再次收到同一 C 操作或直接配对 C 后收到其回传，不会产生新的 B 操作或重复应用；收到缺少因果前置的变更时不提前生效，补齐后恢复并收敛。
- [ ] 不可发现/对端离线仍可本地学习并得到清楚反馈，恢复局域网后自动同步；当前设备选中的词书及未结束练习不被远端会话状态覆盖。
- [ ] 覆盖首次从空数据开始、不会自行清库；既有词书管理、练习及考试行为测试仍通过，桌面手测完成发现、首次配对、后续自动同步及断网恢复。

## Out of Scope

- 旧数据初次合并、云端中继、跨公网、独立的第三方逐条签名验证、已传播历史的撤销与日志压缩策略，以及手动地址发现。
