# 自动交换与端到端同步

**Ticket ID:** T0005
**Source:** [Spec 0004](../../spec/0004-offline-lan-learning-data-sync.md) §Requirement 1–5；[ADR 0009](../../adr/0009-support-offline-multi-device-lan-sync.md)、[ADR 0010](../../adr/0010-discover-lan-peers-with-mdns-and-display-pairing-code.md)
**Status:** Todo

## Goal

已明确配对的设备在 LAN 再次相遇时自动、安全地交换缺失学习变更，断线后恢复并更新可见数据；完成双设备与三设备端到端验收。

## Affected Surfaces

- **Rust 同步服务：** T0001 的增量读取/幂等重放与 T0004 的已授权 Noise 会话之间的交换及重连。
- **Tauri/前端：** `src-tauri/src/lib.rs`、`src/data/wordbooks.ts` 与同步界面的连接状态、同步结果/错误反馈及必要的数据刷新。
- **端到端验证：** 词书、收藏、错题、复习和设置跨两台/三台设备的离线合并，局域网不可用与重复接收。

## Approach

发现已配对对端后自动发起经身份校验的 Noise 连接，只增量交换双方缺少的授权变更，按 T0001 的一致顺序重放 T0002/T0003 的内容与学习事件。断线和重试不能造成漏项或重复计数；在完成持久化后刷新受影响的展示，不覆盖当前选中的词书或未结束的练习。对端离线、mDNS 不可用或配对失败时维持本地功能并向用户呈现状态。A-B 与 B-C 虽已分别配对，A 不应经 B 获得未直接配对的 C 的变更。首发只验收新数据，不自动删除旧数据。

## Dependencies and Coordination

- **Blocked by:** T0001（持久身份/增量与幂等重放）；T0002（词书与收藏操作）；T0003（错题、复习和设置操作）；T0004（先有明确配对的安全连接）。这些都是本票完整端到端验收所必需。
- **Blocks:** 无。
- **Coordination risks:** 与 T0004 共享会话及配对界面，与 T0002/T0003 共享写入后的数据刷新契约；先核对接口，再接入自动交换，避免网络重试直接触发重复业务写入。

## Acceptance

- [ ] 两台全新设备首次核对配对码后分别离线产生词书、收藏、错题、复习和设置变更；再次在同一 LAN 相遇无需人工触发即自动交换，两端最终数据和已确定的业务语义一致。
- [ ] 网络中断、重启、重复连接及乱序抵达后继续交换缺失变更；无重复错题计数、复习完成或已删除词条复活，双方最终收敛。
- [ ] 第三设备仅与 B 配对时，A 不直接或经 B 接收来自 C 的数据；未确认/身份不符设备无法读写同步数据。
- [ ] 不可发现/对端离线仍可本地学习并得到清楚反馈，恢复局域网后自动同步；当前设备选中的词书及未结束练习不被远端会话状态覆盖。
- [ ] 覆盖首次从空数据开始、不会自行清库；既有词书管理、练习及考试行为测试仍通过，桌面手测完成发现、首次配对、后续自动同步及断网恢复。

## Out of Scope

- 旧数据初次合并、云端中继、跨公网、未配对设备的间接传播与手动地址发现。
